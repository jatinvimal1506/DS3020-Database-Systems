# 🗄️ DS3020 - Database Systems
### Indian Institute of Technology, Palakkad

This repository contains lab work from the DS3020 Database Systems course at IIT Palakkad. The labs progressively build core database concepts — from fundamental SQL queries and joins, to stored procedures, triggers, and indexing strategies for query optimization — implemented hands-on using PostgreSQL and pgAdmin.

---

## 🧪 Labs

| Lab | Topic |
|-----|-------|
| Lab 1 | Introduction to Databases — What is a Database, DBMS Concepts |
| Lab 2 | Basic SQL — DDL and DML Commands, CREATE, ALTER, DROP ,SELCCT |
| Lab 3 | SQL Queries — Subqueries, Aggregations, HAVING, CASE |
| Lab 4 | Joins — Inner, Left, Natural Join, Type Casting |
| Lab 5 | Stored Procedures & Functions — PL/pgSQL |
| Lab 6 | Views & Role-Based Access Control — GRANT, REVOKE |
| Lab 7 | Joins & SQL Queries Recap |
| Lab 8 | Triggers — INSERT, UPDATE, DELETE Events |
| Lab 9 | Indexing Basics — B-Tree and Hash Indexes |
| Lab 10 | Advanced Indexing — Multi-column, Covering, and GIN Indexes |
| Lab 11 | NoSQL — MongoDB using PyMongo |

---

## 🛠️ Tech Stack

- **PostgreSQL**
- **pgAdmin 4**
- **PL/pgSQL**
- **MongoDB & PyMongo**
